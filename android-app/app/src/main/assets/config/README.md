# Configuração local

Esta pasta guarda manifestos e mapas de caminhos para os recursos incluídos no APK.

- `resource-manifest.json`: índice estrutural inicial dos diretórios locais.
- Configurações de conexão privadas (tokens, credenciais, chaves) nunca devem ser adicionadas a esta pasta nem ao Git.
- O endereço público do jogo está definido como configuração de compilação no módulo Android.

# Árvores web históricas preservadas

Este diretório contém cópias byte a byte dos arquivos dos módulos antigos, guardados como referência dentro do APK sem substituir o snapshot oficial.

- `algorithomus-app-v1.9/`: árvore web do antigo Algorithomus-App.
- `cobrinha/`: módulo completo do jogo Cobrinha.
- `frutris/`: módulo completo do jogo Frutris.

A lista de caminhos e SHAs de Git Blob está em `legacy-source-tree-manifest.json`. O SHA listado é o identificador de blob GitHub (SHA-1), não SHA-256 do arquivo. Nenhum arquivo foi recompactado ou renomeado dentro das árvores.

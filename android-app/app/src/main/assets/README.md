# Recursos locais do aplicativo

Esta árvore é reservada para os arquivos entregues dentro do APK. Não contém cópias fabricadas do jogo.

- `site/`: HTML, CSS, JavaScript, fontes e demais arquivos necessários para iniciar o simulador localmente.
- `media/`: imagens, áudio, vídeo, quadros, avatares, ícones e mídia escondida usada pelo ARG.
- `data/`: JSON, textos e dados estruturados descobertos na análise.
- `config/`: manifestos de recursos, mapas de caminhos e configurações locais.
- `offline/`: tela de contingência enquanto o conjunto original ainda não foi integrado.

Os diretórios permanecem preparados para receber os arquivos originais posteriormente.
